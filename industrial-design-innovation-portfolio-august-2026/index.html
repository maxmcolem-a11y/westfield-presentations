Scoring rubric

Two common scales.
One meeting gate.

Technical readiness

  1. TRL 6Release-intent prototype; correction loops effectively closed. No current project qualifies.
  2. TRL 5Integrated functional prototype; correction loop remains.
  3. TRL 4Component or partial prototype; core evidence incomplete.
  4. TRL 3Digital or analytical proof; physical kill gate next.
  5. TRL 2Architecture defined; feasibility work has not produced a system prototype.

IP value

  1. 5 · StrategicPotential platform-level claims if the mechanism is manufacturable.
  2. 4 · StrongModerate–High / Moderate–Strong analysis with multiple protectable clusters.
  3. 3 · FocusedSpecific mechanism or combination; broad category claims not supported.
  4. 2 · LimitedNarrow implementation or ornamental opportunity against close prior art.
  5. 1 · LowNo defensible utility mechanism identified; design protection only if form freezes distinctly.
